## Required Visual Language

### Aesthetic
Premium dark fantasy finance game

### Color Palette
- Near-black backgrounds
- Deep navy backgrounds
- Teal/cyan primary glow
- Gold reward accents

### Imagery
- Treasure chest imagery
- Shield imagery

### UI Elements
- Soft luminous borders
- Layered dark cards
- Large readable money amounts
- Circular progress indicators
- Reward and achievement presentation

### Typography
- Consistent spacing and typography

### Responsive Design
Android layouts that adapt without destroying the composition

## Forbidden Visual Results

- Generic Material demo screen
- Flat gray cards
- Basic green banking app
- Cartoon children's game
- Pixel-art game
- Plain spreadsheet appearance
- Unstyled stock Android widgets
- Random gradients
- Emoji used as primary interface artwork
- Entire screenshots used as fake clickable backgrounds
- Static image mockups pretending to be functional UI
- Visually dead buttons
- Placeholder text in a claimed beta build
