# Budget Shield

A native Android budgeting application presented as a game.

## Purpose

**Budget Shield** answers one question:

> How much money can I safely spend right now while still paying every protected bill by its due date?

The result is called **Safe Now**.

## Forbidden Names
Do not rename Safe Now to:
- Cash available
- Balance
- Spending money
- Disposable income
- Cash on hand
